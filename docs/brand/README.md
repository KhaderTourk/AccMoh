# هوية حسابات براند المالية

النظام داخلي لشركة براند، فهويته هي هوية براند.

| الملف | شو هو |
| --- | --- |
| `brand-logo.png` | شعار براند بالحجم الأصلي، خلفية شفافة |
| `brand-logo-512.png` | نسخة 512 بكسل للأيقونات |

![شعار براند](brand-logo-512.png)

## الألوان
| اللون | الكود | الاستعمال |
| --- | --- | --- |
| وردي براند | `#FB005B` | الأساسي: الأزرار والروابط والعناوين المهمة |
| كحلي | `#0B2537` | الثانوي: الشريط العلوي والنصوص الغامقة |
| بنفسجي | `#741446` | درجة بالشعار، للتدرّج أو التمييز |

الخط مش محدد بعد. الأيقونة الخضرا الحالية `#08A46D` بـ`public/assets/icons` بتتبدّل بشعار براند لما نشتغل على الواجهات.
