# قائمة الشاشات

بتنكتب بمهمة «قائمة الشاشات» بقسم 03 باللوحة. كل شاشة برقم، وصورتها الثابتة بـ`docs/ux/screens/` بنفس الرقم.

**مسودة من م. خضر، بستنى مراجعة م. محمد.** شاشات الموقع الموجودة ما بتتصمم من جديد إلا إذا انطلب تعديل. شاشات الآيفون كلها جديدة وبتتصمم قبل الكود.
